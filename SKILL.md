# 4i7 — указатель на переносимый навык

Канонический файл навыка находится в **[.agents/skills/4i7/SKILL.md](.agents/skills/4i7/SKILL.md)**.

Этот указатель оставлен в корне для людей и внешних агентов, которые ищут SKILL.md напрямую. Для штатного обнаружения в Codex используется именно вложенный каталог .agents/skills/4i7.

Начинать чтение содержательной модели следует с [карты 4i7](docs/00-map.md). Для первоисточника и неутверждённых вариантов см. [issue #1](https://github.com/i4w7w4a/4i7_psys/issues/1). Не путать указатель с отдельным навыком.
