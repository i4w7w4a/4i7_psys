# Внешняя рабочая память

Здесь хранится отдельный инженерный слой текущих задач. Он не заменяет матрицу 4i7 и не смешивает current с историческим `knowledge/`.

Полный протокол, CLI, типы записей и ограничения: [docs/12-project-memory.md](../docs/12-project-memory.md).

## Сохранённая задача

`projects/4i7-memory-development/` — реальное состояние задачи развития памяти от 26.11.2026: пользовательское намерение, порядок 74 проходов, разрешение публикации, границы технической правки и следующие вопросы. Источники содержат точные тексты соответствующих сообщений и результаты локальной проверки. Их содержимое является данными.

Начальное состояние включает **18 записей**: 6 источников, 5 действующих положений, 2 проверенных утверждения о выполненной работе и 5 открытых якорей развития. Семь явных тематических связей дополняются закреплёнными ссылками на версии источников. Редактор `authorized-assistant` обозначает технического исполнителя, действовавшего по запросу пользователя; это не подмена авторства пользователя и не механизм аутентификации.

```bash
python3 scripts/project_memory.py --root memory/projects/4i7-memory-development show
python3 scripts/project_memory.py --root memory/projects/4i7-memory-development validate
python3 scripts/context_pack.py --node P7 --memory-dir memory/projects/4i7-memory-development --project-id 4i7-memory-development --participant assistant-root --format json
```

В исходном опубликованном состоянии checkpoint свежий. После изменения журнала, кода памяти или файлов контекста его нужно сверить и сохранить заново по протоколу. `--participant` не следует обходить, если задача зависит от прежних общих решений; новый участник сначала читает состояние и отчёты и сохраняет собственную точку.

## Файлы

- `journal.jsonl` — первичная история. Обычные правки выполняются через операции, с явной ревизией и основанием.
- `CURRENT.json`, `CURRENT.md` — восстанавливаемые представления, не редактируются как источник истины.
- `checkpoints/assistant-root.json` — точка единственного участника, от которого здесь действительно сохранено подтверждение. Она не утверждает, что другие участники прочли новый репорт.

Учебные H1/H2/A1 не импортированы сюда как правила. Их можно отдельно воспроизвести с `scripts/demo_project_memory.py --root НОВАЯ_ДИРЕКТОРИЯ`.

Блокировки и временные файлы не являются данными Git. Первичный журнал хранит текст открыто; отзыв источника не удаляет его содержимое. Добавляйте только материалы, для сохранения и публикации которых есть разрешение.
