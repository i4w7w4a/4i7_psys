# 4i7

4i7 — философская основа для создания синергических систем. Она помогает видеть целое через связи между его частями, менять точку зрения и возвращаться к замыслу с новым пониманием.

**[Открыть карту системы](docs/project-map.md)** · [Полная матрица](https://github.com/i4w7w4a/4i7_psys/blob/bb9c34dac403a208feb8c51787b69e5386ad58c9/docs/09-matrix.md) · [Словарь](https://github.com/i4w7w4a/4i7_psys/blob/5f106e8ba9057ed79aa65868d1aebf54890606d2/docs/glossary.md) · [Визуальный атлас](https://github.com/i4w7w4a/4i7_psys/blob/05d0064cafc2b75da054d9c94fd41d7e1168ff71/docs/research/visual-atlas-20261113/README.md)

[![Устройство 4i7. Наблюдатель i выбирает, на какой из семи столпов направить внимание. У каждого столпа четыре стороны и по два аспекта на сторону.](docs/assets/system-map.svg)](docs/project-map.md)

Например, когда в целом пока не видна одна связь, в матрице есть место для самого вопроса. Адрес `P3.2.1` указывает на Скелет связей, его вторую сторону и первый аспект. Здесь можно отметить пробел и вернуться к нему, когда станут понятны соседние части. [Авторское уточнение](https://github.com/i4w7w4a/4i7_psys/issues/12#issuecomment-6878642283)

На карте приведена **рабочая матрица на 19 ноября 2026 года**. Описаны все 56 аспектов семи столпов. Для каждого столпа на карте есть ссылка на его стороны, а для последней редакции — на [решение автора](https://github.com/i4w7w4a/4i7_psys/issues/12#issuecomment-7019427154).
