# Инструкции агентам, работающим с 4i7_psys

Этот репозиторий — **исследуемая спецификация авторской модели 4i7**, не готовая ОС и не требование внедрить новую архитектуру.

Если задача касается 4i7, сначала прочитай:
1. .agents/skills/4i7/SKILL.md — правила применения навыка;
2. docs/00-map.md — карта и ссылки;
3. docs/01-observer.md, docs/02-directions.md, docs/03-relations.md — только по мере необходимости;
4. нужные docs/pillars/*.md и model/4i7.json;
5. при работе с новыми знаниями — docs/06-evolution.md, knowledge/README.md и knowledge/index.json;
6. [issue #1](https://github.com/i4w7w4a/4i7_psys/issues/1) — источник исходных смыслов и открытых гипотез.

**Обязательное различие:** слова автора, рабочие интерпретации, предложенные механизмы и подтверждённые факты — разные уровни. Не заполняй 28 смысловых ячеек механически и не называй предполагаемые спирали доказанными алгоритмами. Не переписывай чужую OS, пока не выполнено сопоставление с её существующим устройством.

Правка карты должна сохранять согласованность текста и model/4i7.json. Для проверки запускай стандартный Python 3: python3 scripts/validate_model.py и python3 scripts/validate_knowledge.py.

Изменения модели оформляй через PR; решения по смыслу и закреплению четырёх сторон требуют обсуждения с автором. Для нерелевантных задач навык 4i7 не обязателен.


**Живость модели:** новые источники фиксируй карточками, а не немедленным переписыванием семёрки. Запись с `captured` не может без отдельного решения стать каноном. При изменениях сохраняй исходную редакцию через Git и связывай решение с записью, а найденные противоречия делай видимыми.


Для задачи конкретного столпа собери временный контекст через `python3 scripts/context_pack.py --node P3` (замени P3 на нужный узел). Для исследовательских кандидатных тезисов добавь `--include-candidates`; их статус не следует повышать при передаче другому агенту. Работу без запуска скрипта можно продолжить ручным чтением JSON и исходных карточек. Скрипт является локальным селектором, а не vector store.
