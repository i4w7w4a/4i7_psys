# Машиночитаемый каркас 4i7

**4i7.json** — концептуальный граф версии 0.1.0, помеченный **research**. Он содержит точку i, семь столпов, четыре адресуемых направления каждого (28 уникальных адресов), иллюстративные маршруты и гипотетические отношения.

Это описание **структуры гипотез**, не исполняемый оркестратор. Значения всех side_positions намеренно null со статусом unassigned. Документы docs являются толкованием; issue #1 сохраняет авторские исходные формулировки.

Принципы изменений:
- Не менять id P1…P7 и Pn.front/right/back/left без плана миграции.
- Смена смысла должна сопровождаться источником авторского решения и изменениями в docs.
- Не превращать статус hypothesis в согласованный без решения автора.
- Не считать расстояние между эмбеддингами направлением взгляда.

Проверка целостности: python3 scripts/validate_model.py.
