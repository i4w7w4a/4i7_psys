# Четыре направления: открытые стороны каждого столпа

На данный момент имеются **четыре позиции взгляда** — спереди (front), справа (right), сзади (back), слева (left). Это **геометрические метки для маршрута**, а не четыре навсегда определённых психологических, организационных или инженерных роли.

Семь столпов × четыре позиции = **28 адресуемых позиций**. Наличие адреса не означает наличия доказанной содержательной функции.

## Что нужно определить исследованием

- Одинакова ли семантическая грамматика сторон для всех столпов или у каждого она собственная?
- Какие наблюдения возникают на стороне, которых не было с других сторон?
- Каков предмет передачи между позициями: вопрос, ограничение, факт, гипотеза, решение, возражение?
- Какие переходы действительно добавляют смысл, а какие лишь повторяют его?
- Как проверить полезность второго вращения, не выдавая число посещений за число открытий?

## Пробные ракурсы (пока НЕ сопоставлены с направлениями)

Для **3 Голоса**: слушать, уточнять, формулировать, передавать.

Для **4 Баланса**: ценность, связность, ресурсы, риск.

Не назначай «слушать = спереди» или «риск = слева» без отдельного аргумента и решения автора. Остальные столпы пока сохраняют четыре незаполненные позиции.

## Адресация

Позиции можно адресовать стабильным кодом вроде P3.front или P7.left. Поле side_positions в model/4i7.json фиксирует для каждой позиции статус **unassigned**. Это позволяет строить граф, обсуждать каждую сторону и со временем добавлять значение, не переписывая идентификаторы.

Простой пример гипотетического маршрута: P1.front → P2.right → P3.back → P4.left → P5.front → P6.right → P7.back. При обратном вращении из того же старта: P1.front → P2.left → P3.back → P4.right → P5.front → P6.left → P7.back. Эти последовательности — иллюстрации порядка, а не обязательные правила решения любой задачи.

Расширение глубины включается только при существенном пробеле, высокой цене ошибки либо обнаруженном противоречии.
