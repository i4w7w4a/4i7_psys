# Журнал решений

Если новая информация меняет принципиальное определение столпа, его четыре стороны, устойчивую связь или правило навыка, создай отдельное решение `DR-YYYYMMDD-NNN.md` по [шаблону](../templates/decision.md).

Запиши прежнее состояние, новую гипотезу, источники, доводы за и против, затронутые идентификаторы, условия отката и подтверждение автора. Свяжи решение с ID соответствующей карточки знания. Пока таких согласованных решений не записано; первоначальное наличие каркаса не делает его неизменным каноном.
